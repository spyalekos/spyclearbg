# SpyClearBG 🖼️

> Αυτόματη αφαίρεση φόντου από φωτογραφίες με Τεχνητή Νοημοσύνη και γραφικό περιβάλλον Flet.

---

## 🌟 Χαρακτηριστικά

- **Λειτουργία βάσει φακέλου**: Επιλογή φακέλου με αυτόματο εντοπισμό όλων των υποστηριζόμενων εικόνων (`.jpg`, `.jpeg`, `.png`, `.webp`, `.bmp`).
- **Προεπισκόπηση side-by-side**: Άμεση προβολή της αρχικής εικόνας και του επεξεργασμένου αποτελέσματος δίπλα-δίπλα σε πραγματικό χρόνο.
- **Πληθώρα μοντέλων AI**:
  - `u2net` — Γενικής χρήσης μοντέλο υψηλής ακρίβειας (προεπιλογή).
  - `u2netp` — Ελαφρύ και γρήγορο μοντέλο για συσκευές με περιορισμένους πόρους.
  - `u2net_human_seg` — Εξειδικευμένο για ανθρώπινες φιγούρες και πορτρέτα.
  - `u2net_cloth_seg` — Εξειδικευμένο για ρούχα και ενδύματα.
  - `siluela` — Εξειδικευμένο για σιλουέτες και φωτογραφίες προϊόντων.
  - `isnet-general-use` — Μοντέλο υψηλής ακρίβειας γενικής χρήσης.
  - `isnet-anime` — Εξειδικευμένο για σχέδια, σκίτσα και anime.
- **Alpha Matting**: Ρύθμιση Foreground/Background thresholds και Erode size για βέλτιστα αποτελέσματα σε δύσκολες λεπτομέρειες (μαλλιά, φτερά, λεπτές γραμμές).
- **Μόνο μάσκα (Only Mask)**: Παραγωγή ασπρόμαυρης μάσκας αποκοπής αντί για διαφανές αποτέλεσμα.
- **Μετα-επεξεργασία (Post-processing)**: Αυτόματη λείανση ακρών της μάσκας για φυσικότερη αποκοπή.
- **Προσαρμοσμένο χρώμα φόντου**: Δυνατότητα ορισμού συγκεκριμένου χρώματος (R, G, B, A) στο φόντο αντί για διαφάνεια.
- **Ομαδική επεξεργασία (Bulk Processing)**: Επιλογή πολλαπλών εικόνων και μαζική αφαίρεση φόντου με ένα κλικ.
- **Ασύγχρονη εκτέλεση**: Πλήρης διαχωρισμός επεξεργασίας σε background threads — το γραφικό περιβάλλον παραμένει άμεσο και αποκριτικό.
- **Διαχείριση αρχείων**: Άμεσο άνοιγμα αρχικής εικόνας ή αποτελέσματος στον εξερευνητή αρχείων (Explorer) και δυνατότητα διαγραφής αποτελέσματος.
- **Premium σχεδίαση**: Σκοτεινό πράσινο θέμα (Dark green theme) με glassmorphism αισθητική.

## 🛠️ Οδηγίες Χρήσης & Αποθήκευση Αποτελεσμάτων

- **Αποθήκευση Αποτελεσμάτων**:
  - Τα αποτελέσματα αποθηκεύονται αυτόματα στον ίδιο φάκελο με την αρχική εικόνα, προσθέτοντας την κατάληξη `_nobg.png` (ή την προσαρμοσμένη κατάληξη που ορίζεται στις ρυθμίσεις).
- **Εκτελέσιμο**:
  - Το αυτόνομο εκτελέσιμο εκκινεί άμεσα χωρίς να απαιτεί προεγκατεστημένο περιβάλλον Python στο σύστημα.

## 📚 Τεχνολογίες
